# macOS ISO Download Links Full Version for ISO 2026
<p dir="auto">Hello everyone. This repository contains the RAW macOS installation files and global EFI needed to install macOS on your <code>compatible</code> computer. I am going to share with you my own OpenCore bootloader folder and macOS installation files. If you send me the problems you encounter, we can work together to solve them. I will update it externally with the image every month as there is no EFI folder in the installation file. What you need to do is to place the EFI folder in the EFI partition that will be created after you have written the installation file to your USB flash drive. I hope you all have a smooth hackintosh.</p>

<h3 class="heading-element" dir="auto" tabindex="-1">Post Installation</h3>
&nbsp;

</div>
&nbsp;
<ul dir="auto">
 	<li>Open config file with <code>Text Edit</code>.
<ul dir="auto">
 	<li>Search <code>HideAuxiliary</code> and change <code>false</code> value to <code>true</code>.</li>
 	<li>Search <code>SecureBootModel</code> and change <code>Disabled</code> value to <code>Default</code>. (Big Sur+)
<ul dir="auto">
 	<li>If you have patched your system with <code>OCLP</code>, do not do this step.</li>
</ul>
</li>
 	<li>Search <code>boot-args</code> and delete <code>-v</code> argument.</li>
</ul>
</li>
 	<li>Now we have to set our serial numbers and ROM value.
<ul dir="auto">
 	<li>Download <a href="https://github.com/corpnewt/GenSMBIOS/archive/refs/heads/master.zip">GenSMBIOS</a> and open .command file. If program asks <code>Download Python</code> download it. After that select option 3.</li>
 	<li><a href="https://github.com/yusufklncc/Lenovo-Thinkpad-E570-Hackintosh/blob/main/Resources/GenSMBIOS/GenSMBIOS%201.png" target="_blank" rel="noopener noreferrer"><img src="https://github.com/yusufklncc/Lenovo-Thinkpad-E570-Hackintosh/raw/main/Resources/GenSMBIOS/GenSMBIOS%201.png" /></a></li>
 	<li>Now list 5 SMBIOS first. <code>MacBookPro14,1</code> (Compatible SMBIOS with your hardware)
<ul dir="auto">
 	<li>If your hardware compatible SMBIOS doesn't support installed macOS version, add <code>-no_compat_check</code> to <code>boot-args</code>.</li>
</ul>
</li>
 	<li><a href="https://github.com/yusufklncc/Lenovo-Thinkpad-E570-Hackintosh/blob/main/Resources/GenSMBIOS/GenSMBIOS%202.png" target="_blank" rel="noopener noreferrer"><img src="https://github.com/yusufklncc/Lenovo-Thinkpad-E570-Hackintosh/raw/main/Resources/GenSMBIOS/GenSMBIOS%202.png" /></a></li>
 	<li>Select and copy first Serial.</li>
 	<li><a href="https://github.com/yusufklncc/Lenovo-Thinkpad-E570-Hackintosh/blob/main/Resources/GenSMBIOS/GenSMBIOS%203.png" target="_blank" rel="noopener noreferrer"><img src="https://github.com/yusufklncc/Lenovo-Thinkpad-E570-Hackintosh/raw/main/Resources/GenSMBIOS/GenSMBIOS%203.png" /></a></li>
 	<li>Go <a href="https://checkcoverage.apple.com/" rel="nofollow">check</a> serial number. Your serial should be like this. If not, try second serial.</li>
 	<li><a href="https://github.com/yusufklncc/Lenovo-Thinkpad-E570-Hackintosh/blob/main/Resources/GenSMBIOS/Check%20Serial.png" target="_blank" rel="noopener noreferrer"><img src="https://github.com/yusufklncc/Lenovo-Thinkpad-E570-Hackintosh/raw/main/Resources/GenSMBIOS/Check%20Serial.png" /></a></li>
 	<li>Search MacBookPro15,1 and replace <code>Type &gt; SystemProductName, Serial &gt; SystemSerialNumber, Board Serial &gt; MLB and SmUUID &gt; SystemUUID</code> values. Now we will set our ROM value.</li>
 	<li>Go <code>System Setting &gt; Netwotk &gt; Ethernet &gt; Details &gt; Hardware</code>. If our MAC adress is <code>54:1A:AF:43:70:CA</code> remove <code>:</code> characters = <code>541AAF4370CA</code>. Convert it to <a href="https://base64.guru/converter/encode/hex" rel="nofollow">Base64</a>.</li>
 	<li>Now we have <code>VBqvQ3DK</code>. Replace this with ROM value and save config file.</li>
 	<li>Restart computer and press <code>Space</code> key on OpenCore menu. Then enter <code>ResetNVRAM</code>. After that BIOS settings may change. Check it and boot macOS.</li>
 	<li>Now you can login iCloud, iMessage or other apple services and you can use macOS.</li>
</ul>
</li>
</ul>
